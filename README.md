# CIVIO Corporate Website

เว็บไซต์ต้นแบบ CIVIO / Massdyna โทนเขียวธรรมชาติ–ครีม ออกแบบให้หน้าแรกเน้นการเลือกชมผลิตภัณฑ์ 2 รายการ และแยกรายละเอียดเชิงลึกไว้ในหน้าของแต่ละผลิตภัณฑ์

## โครงสร้างผลิตภัณฑ์

- `index.html` — หน้าแรก แสดงผลิตภัณฑ์ด้วยแถบเลือก 2 รายการและภาพแบบ carousel สลับชมได้ มีปุ่มไปหน้ารายละเอียดสินค้า
- `product-civio.html` — หน้าเครื่องกำจัดขยะเศษอาหาร CIVIO แสดงคุณสมบัติ วิธีใช้งาน 4 ขั้นตอน วิดีโอ และส่วนระบบ IoT
- `product-novabinq.html` — หน้าถังขยะอัจฉริยะ NovaBinQ แสดงองค์ประกอบ 5 ระบบและภาพรวมการใช้งาน 4 ขั้นตอน

## จุดเด่นที่ปรับในเวอร์ชันนี้

1. เมนู “ผลิตภัณฑ์” ด้านบนมีตัวเลือกสินค้า 2 รายการ และมีปุ่มเลือกสินค้า 2 ปุ่มอยู่เหนือภาพ carousel ในหน้าแรก
2. หน้าแรกตัดข้อมูลขั้นตอนใช้งาน รายละเอียดระบบ และวิดีโอสินค้าออก เหลือเพียงภาพสินค้า จุดเด่นสั้น ๆ และปุ่ม “ดูรายละเอียดสินค้า”
3. เพิ่มหน้าแยกของเครื่อง CIVIO พร้อมส่วนระบบ IoT อ้างอิงจากสไลด์ที่ระบุการติดตามสถานะเรียลไทม์ การแจ้งเตือนอัตโนมัติ รายงานข้อมูลเชิงลึก และการควบคุมระยะไกล
4. เพิ่มหน้าแยก NovaBinQ พร้อมองค์ประกอบตามสไลด์ ได้แก่ กล้อง AI, หน้าจอควบคุม, ถาดเอียงอัตโนมัติ, ถังรองรับ 4 ช่อง และโครงสร้างสเตนเลส
5. เก็บช่องทางติดต่อไว้ที่หน้าแรกส่วนล่างเหมือนเดิม และลิงก์จากหน้ารายละเอียดสินค้ากลับไปยังส่วนนั้น

## เปิดใช้งาน

1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `CIVIO-Website` ใน Visual Studio Code
3. เปิด `index.html` ด้วย Live Server หรือเปิดไฟล์โดยตรง
4. ทดลองเมนู “ผลิตภัณฑ์” และปุ่มเลือก 01 / 02 จากหน้าแรก จากนั้นกด “ดูรายละเอียดสินค้า” เพื่อไปยังหน้าแยก

ไม่ต้องติดตั้ง Node.js หรือฐานข้อมูลสำหรับการแสดงผลเว็บไซต์ต้นแบบ

## หมายเหตุ

- ข้อมูลระยะเวลา 24 ชั่วโมง การลดปริมาณ 80–90% และวัสดุ Stainless Steel 304 อ้างอิงจากสไลด์นำเสนอ ผลจริงอาจแตกต่างตามรุ่น วัตถุดิบ และเงื่อนไขการใช้งาน
- ความสามารถ IoT อ้างอิงจากสไลด์นำเสนอ ความสามารถจริงขึ้นอยู่กับรุ่นและระบบที่ติดตั้ง
- ขั้นตอน NovaBinQ เป็นภาพรวมตามแนวคิดที่สไลด์แสดง ควรให้บริษัทสาธิตและยืนยันประเภทขยะที่รองรับก่อนใช้งานจริง
- วิดีโอเครื่อง CIVIO ฝัง YouTube ID `NRCYyO5xy0o` ในหน้ารายละเอียดสินค้า ส่วนสไลด์ NovaBinQ ไม่มี URL/Video ID เฉพาะรุ่น จึงไม่ฝังวิดีโออื่นแทน
- แบบฟอร์มติดต่อที่หน้าแรกใช้ `mailto:` เพื่อเปิดโปรแกรมอีเมลของผู้เข้าชม ไม่ได้ส่งเข้าฐานข้อมูลหรือระบบอีเมลอัตโนมัติ
- รูปภาพภายนอกและ Google Fonts บางส่วนต้องใช้อินเทอร์เน็ตจึงจะแสดงผลครบ
